# Probetest – Zwischenklausur A1.2 (German 2, VGU)

Web thi thử tiếng Đức A1.2 theo đúng format Zwischenklausur của German 2 (GER2_MC1), dùng kèm Safe Exam Browser (SEB) giống bài Probetest_SEB trên Moodle.

## Cách dùng

1. Mở trang chủ của web (GitHub Pages) — có 2 nút:
   - **Download**: tải file cấu hình `thi-thu.seb` về máy.
   - **Run**: mở thẳng bài thi thử (`exam.html`).
2. Muốn thi như thật: cài Safe Exam Browser (Windows 3.10 / macOS 3.6), rồi mở file `thi-thu.seb` — SEB tự khóa màn hình và mở bài thi.
3. Mật khẩu bắt đầu / thoát SEB: `123456` (giống Probetest của trường).

## Nội dung bài thi (50 phút, 50 điểm)

| Phần | Nội dung | Điểm |
|---|---|---|
| 1. Chunks-Test | 20 câu trắc nghiệm a–d từ Einheitstests 9–12 (Das Leben A1) | 20 |
| 2. Hören | Teil 1: 6 hội thoại ngắn (a/b/c) · Teil 2: 4 thông báo (Richtig/Falsch), kèm file nghe gốc | 10 |
| 3. Lesen | Teil 1: 2 e-mail/thư (Richtig/Falsch) · Teil 2: 5 câu chọn quảng cáo (a/b) | 10 |
| 4. Schreiben | Viết e-mail thân mật cho Christian Schmitz (3 ý), có bài mẫu đối chiếu sau khi nộp | 10 |

Trang thi có đồng hồ đếm ngược 50 phút, hết giờ tự nộp, nộp xong tự chấm phần trắc nghiệm và hiện đáp án.

## Cấu trúc thư mục

- `index.html` — trang chủ với 2 nút Download / Run
- `exam.html` — bài thi thử
- `thi-thu.seb` — file cấu hình SEB (dựa trên config gốc của Probetest_SEB, trỏ về web này)
- `audio/teil1.mp3`, `audio/teil2.mp3` — file nghe phần Hören

Nguồn tài liệu: thư mục Prüfungstraining_ZK_A1.2 và Chunks: Einheitstests 9–12 trên Moodle khóa German 2 (dùng cho mục đích tự học).
